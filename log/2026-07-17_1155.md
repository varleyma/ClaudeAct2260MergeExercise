# Progress Log — July 17, 2026 @ 11:55 AM

## Session Summary
New sub-project: compare the **homeownership rate implied by the reports panel**
against the **implied rate from the karibe property-record name search**, to
gauge how completely that search found decree holders who own PR property.

## Key Realization
The annual reports are **redacted (no names)**, so panel records cannot be linked
person-to-person with the named property records. This is therefore an
**aggregate-rate comparison**, not an individual match.

## Approach (code/stata/homeownership_comparison.do)
- **Reports side:** Built a filename→(Own/Rent, primary_property_value) crosswalk
  from all 7 raw report files (proper CSV parsing in Stata), merged onto the panel
  (100% of 8,446 rows matched), collapsed to person level (4,726 unique filers).
  A person "owns" if any report-year shows Own / primary value>0 / re>0.
- **Karibe side:** Normalized names (accent-strip, uppercase, punctuation→space)
  and matched `names_individuos22/60` first+last (whole-word) against karibe
  `titular`. Rate = share of decree names appearing on ≥1 property record.
- Output: `output/homeownership_comparison.txt`; intermediates in `data/clean/`.

## Results
| Measure | Rate |
|---|---|
| Reports: owns primary home (ever) | 57.9% |
| Reports: owns real-estate assets re>0 (ever) | 49.2% |
| **Reports: owns ANY property (ever)** | **62.3%** (2,944 / 4,726) |
| Karibe search — Act 22 names | 50.3% (1,574 / 3,132) |
| Karibe search — Act 60 names | 54.0% (1,416 / 2,620) |
| Karibe search — all names | 52.0% (2,990 / 5,752) |

**Takeaway:** Reports say ~62% of Act 22 filers own PR property, but the name
search found property for only ~50% of Act 22 names. Since the search rate is an
UPPER bound (same-name false positives inflate it) yet still sits below the true
ownership rate, the search **missed at least ~19%** of property-owning decree
holders (implied recall ceiling ≈ 81%; true recall is lower once false positives
are netted out).

## Caveats
- Aggregate comparison only (reports anonymized).
- Different populations: report filers vs. all named decree holders.
- Reports = self-reported primary home + RE assets; karibe = any registry
  property (primary/investment/timeshare).
- Karibe name match is exact-normalized whole-word; nicknames, name-order
  variants, and Hispanic two-surname conventions may cause additional misses
  (pushing true recall lower still).
