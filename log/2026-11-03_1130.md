# Log — 2026-11-03 11:30 — Investor-begets-investor arrivals DiD (event study)

## Goal
User wanted DiD/event-study evidence of investor clustering (not just the
descriptive fig_cluster_exposure from the morning session): does an investor
purchase RAISE subsequent investor arrivals nearby?

## Design
Outcome = arrivals of OTHER decree investors (other design1 events, other
normalized buyer names; events already group same-buyer-same-day parcels) per
km² in rings around each event, annual, zero-filled grid. Rings mirror the
headline price spec: 0-250/250-500/500-1000/1000-1500 vs CONTROL 1500-2000m.
lpdid per bin (pre 4 / post 3, nevertreated, window ±6y), exactly the
design1_decay_results.do conventions; stacked ppmlhdfe robustness
(absorb event×bin + event×year, cluster event).

KEY METHOD POINT: the naive "pioneer" flag (no prior event within 1km at the
event date) conditions on the pre-period outcome — pre-window arrivals are
ZERO BY CONSTRUCTION. Estimation split uses PIONEER4 instead: no other-buyer
event within 1km dated before t−4y (predetermined w.r.t. the lpdid
pre-window). pioneer4 = 465/1,160 events; naive pioneer = 237 (kept in data,
documented, not used for estimation).

## Results (arrivals/km²/yr vs control band, ref t−1)
- ALL events (n=1,160): strong NEGATIVE pooled Pre everywhere (0-250m:
  Pre −0.93***, Post +0.95***; ES ramps smoothly −1.46 → −0.40 pre,
  +0.77/+0.48/+0.68/+0.85 post). Post roughly CONTINUES the pre-slope →
  no clean causal kink. Interpretation: spatiotemporal cluster momentum +
  event-timing endogeneity (each event is itself an arrival drawn by the same
  momentum). Quantifies clustering directly but NOT state dependence alone.
- PIONEER4 events (n=465): much flatter pre (0-250m ES: −0.50/−0.24/−0.15/0;
  pooled Pre −0.29**) and post that ACCELERATES AWAY from the pre pattern:
  +0.27/+0.21/+0.51/+0.92*** by τ+3 (pooled Post +0.60***). Spatial gradient
  intact (250-500m Post +0.17**, 500-1000m +0.08***, 1-1.5km +0.04**).
  PPML pioneer 0-250m: pre mean −0.12, post +0.43 log points vs control.
  → Suggestive STATE DEPENDENCE: first investor in (near-)virgin territory is
  followed by accelerating arrivals; residual mild pre-ramp at τ−4 flagged.
- Established (n=695): biggest levels both pre and post (momentum story).

## Framing for the paper
Panel A = direct DiD quantification of clustering dynamics (honest: momentum,
not a jump); Panel B = the state-dependence test. Pairs with
fig_cluster_exposure (descriptive) and motivates the concentration channel.
Candidate upgrades: honestdid-style sensitivity on the pioneer pre-ramp;
dose (n_prior_tm4) gradient; hazard-style first-subsequent-arrival spec.
